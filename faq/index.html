Frequently Asked Questions

Our parish forgot its join code. How can the rector find it?

The rector can look it up at any time; nothing needs to be written down in advance. Only the rector can see the code. Helpers the rector has authorized cannot.

  1. Open the parish sign-in page at theuniversaloffice.com/parish/.
  2. Enter the email address the parish was registered with, and choose Send code. A 6-digit code is emailed to that address. It expires in 10 minutes. There is no password.
  3. Enter the 6-digit code and choose Sign in.
  4. Under Who can follow your parish, find Your join code. It looks like ABCD-EFGH. Choose Copy code to copy it.

Give the code to the people in the parish. They enter it once in their app or browser.

If the code has spread further than intended, choose Make a new code on the same page. The old code stops working and everyone who used it is signed out of the prayer list until they enter the new one. Do this only when needed.

The Your join code section appears only for a parish that is set to Only people with the join code. A parish set to be public has no code. If the section is missing, check the setting just above it.
